# git-petri

Твои репозитории на GitHub, GitLab и Gitea растут на чашке Петри прямо в терминале.

```bash
git clone https://github.com/Baklatech/git-petri && cd git-petri && ./install.sh
git-petri          # спросит провайдера и токен
git-petri --demo   # без сети и токена
```

[Подробно](docs/guide.md).
